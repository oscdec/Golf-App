# Resonant Golf: notes for Claude

The app is named **Resonant Golf** inside the app (title, header) and **Resonant** on the home screen (`short_name`). Icon: a ball-flight arc rising into an orange target, on blue (#1d4e8c).

Personal installable web app (PWA) for one golfer, used on Android in Chrome. Hosted on GitHub Pages from `main`, at https://oscdec.github.io/Golf-App/. The owner is not a developer: explain in plain words, and never ask them to run commands.

## Structure
- `index.html`: app shell. Each tab is a `<main class="view" data-tab="...">`; bottom nav switches tabs by `#hash` (first part before `/`).
- `css/app.css`: all styles. Colors and fonts are tokens on `:root`, with dark-mode overrides. Palette (Nov 17): blue and orange to match the logo, lightly saturated: `--back` blue accent, `--down` orange-red for misses/over-time, `--done` amber for completed sessions and days (text on fills uses `--on-back`/`--on-down`/`--on-done`).
- `js/store.js`: shared storage helpers (`Store`). All data keys start with `rg.` (plus Tempo's older `tempoFrames`).
- `js/handicap.js`: World Handicap System index estimate (`Handicap`); also loads in Node for testing.
- `js/backup.js`: backup/restore of every app key to a JSON file (`Backup`); panel lives in the Insights tab.
- `js/tempo.js`: Tempo tab, wrapped in its own function scope. Add each new tab as its own `js/<tab>.js`.
- `js/rounds.js`: Rounds tab. Screens are sub-routes of `#rounds/...` so the phone's back button works. Exposes `Rounds.index()`.
- `js/notes.js`: Notes tab (`Notes`): seven boxes (General, Mental, Driver, Irons, Wedges, Chipping, Putting). The box is a draft (autosaved as typed, marked "Not saved yet" until Update). Update (Nov 18) saves a dated copy to Previous Notes (last 5 kept, no duplicate if unchanged) and **leaves the text in the box**, with Undo; Previous Notes lists them (always tappable; with nothing saved yet it explains Update) with Put Back In The Box. Boxes left empty by the old clear-on-Update get their last update back on load. `Notes.get(area)` (the latest Update, else the box text) is used by practice sessions.
- `js/sessions.js`: the suggested week and the session runner (`Sessions`): week card on the Practice home, `#practice/s/<id>` (start alone, move to another day, mark done), `#practice/run` (clock panel at the top: the routine section's countdown as the big clock when a routine runs, otherwise the block's; then block left, practiced, left in session, planned; pause/skip/end, games launch from the block, matching notes), `#practice/sum/<runId>[/new]` (the session's name once as the heading, then one card per block: routine name only if it differs or there are several blocks, time, Shortened note, scores, games), `#practice/edit/<runId>` (edit a finished session), `#practice/checkout` (the day's check-out), `#practice/open` (Open Practice setup). Past Sessions (last 20, folded away under a large heading) on the Practice home, each with Delete (`deleteRun`: removes its practiceLog rows and this week's done marks; games stay in their own history; the day's check-in moves to another session that day, or goes if none is left); Delete Session also on a past summary. A clock bar shows on other Practice screens while a session runs.
- `js/practice.js`: Practice tab (week plan from `Sessions`, then Games grouped by discipline). Each game = setup + a log of inputs; progress and results are worked out by replaying the log, so Undo just pops it. Sub-routes of `#practice/...`; `#practice/ge/<id>` edits a finished game's log row by row (`TOTAL` = entries in a full game for fixed-length games; ladder, must and lag are open-ended with Remove/Add). A game's minutes are logged once (`logGame`, flag `logged`), so Continue This Game doesn't double-count.
- `js/insights.js`: Insights tab with a Course / Practice toggle at the top (`rg.insightsView`). **Course**: handicap index, scores with 12-round rolling average, Tiger 6 mistakes per round with a type picker and per-type averages, penalty strokes per round, GIR+1 per round, scoring by par type, scoring mix per round (per-round trend charts show dots plus a 12-round rolling average), with a range filter (last 10/20/40 rounds, or 3 months to all; for the handicap chart, "last N" means the last N scores including past GHIN scores); reads `Rounds.history()` and `Rounds.list()` (each round has `t6` per type, `t6total`, `pen`, `gir1`). **Practice** (no range filter): How Practice Feels at the top (last 60 days of `rg.checkins` grouped by session on a date axis: a boxed reading key (before/after colours, what orange above or below blue means, filled = yes / ring = no, tap for answers), then happiness before = blue `--s1` and after = orange `--s2` joined by a line, then Before/After strips for Having Fun? and Golf In The Way Of Real Life? with filled = yes, ring = no; average before/after/change, "lower after" count and a one-line verdict); Practice Time (minutes per week, last 8 weeks, stacked by discipline from `rg.practiceLog`); Games (picker per variant, results as dots + 12-game average to beat, via `window.PracticeMeta` from practice.js); Routines (picker per routine; each scored step as % per session, seq steps as On Line / In Window, the spiral's farthest distance as its own chart; titles via `Sessions.routineTitle`). Hand-built SVG with tap tooltips and "Show numbers" tables.
- `js/app.js`: tab switching, service worker registration, install button, persistent-storage request.
- `sw.js`: offline cache. App files are network-first, fonts cache-first.
- `manifest.webmanifest`, `icons/`: install metadata.
- `tests/`: Playwright browser tests for Claude (see tests/README.md); not loaded by the app. Run them all before every release.

## Rules
- **Bump `VERSION` in `sw.js` on every release**, and add any new file to its `APP` list.
- No build step and no frameworks. Plain HTML, CSS and JS so the files deploy as-is.
- Use relative paths only (the site lives under `/Golf-App/`).
- Data goes in browser storage on the phone via `Store`, under `rg.` keys, so backup/restore picks it up automatically. Never store app data under other keys.
- Data keys: `rg.courses` (courses with tees: rating, slope, par[18], si[18]), `rg.rounds`, `rg.tags` (feel tags), `rg.pastScores` (GHIN differentials entered by hand), `rg.meta` (last backup time), `rg.games` (practice games: game, variant, setup, log, status active/done/failed, result), `rg.insightsRange` (chosen date range), `rg.insightsView` (course or practice), `rg.notes` ({cur, edited, hist}), `rg.plan` (usual week), `rg.week` (this week: days per slot, done per session; resets each Monday), `rg.run` (session in progress), `rg.practiceLog` (minutes per block: date, session, discipline, done, games), `rg.settings` (normal driver carry, alarm), `rg.checkins` (see check-ins below).
- Rounds decisions: blind scoring (no par, total or score-to-par while a round is in progress); per hole: shots to green, putts, penalties, D/T/115/DC taps; 3p, 5 and GIR+1 are derived; no fairways; best 3 shots is the last step; PCC added after from GHIN.
- Games: Beat Your Average = mean of the last 12 finished games of the same variant (e.g. ladder-irons-hard); failed Lag Putt games and shortened games (`short:true`) are left out. Each game is higher- or lower-is-better.
- Shortened (Nov 18): End Early saves a game with `short:true`; any finished game can be marked shortened or counted normally; an incomplete one offers Continue This Game. Routines get a Mark As Shortened toggle (`short:true` on the practiceLog entry). Shortened games and routines stay in history and their minutes count, but they're left out of averages, bests and Insights.
- Chart colors are tokens `--s1`..`--s4` (validated categorical palette, light and dark); keep series in that fixed order and keep direct labels + the numbers table, since two light-mode colors are under 3:1 contrast.
- The app always opens on the Practice tab (an inline script in index.html replaces any other #tab on load; resuming a backgrounded app keeps its place). Tab order: Practice, Rounds, Notes, Tempo, Insights (five tabs).
- Week plan: slots Mon–Fri plus one Weekend slot (Sat or Sun). Sessions are units (60 or 30 min); a 30-minute session can be moved alone, splitting it from its partner. Done sessions/days are highlighted. Default week: Tue Technical Ball Striking (pick Center Strike / Startline or Face Control / Tempo when starting); Wed Technical Chipping + Technical Putting; Thu Ball-Striking Combine + Wedge Combine; Fri Chipping Game + Putting Game; Weekend Wedge Session + Ball Striking – Freestyle (20 min, optional: not in the done total, no structure). Sessions are moved by dragging the handle on the week card (pointer events, works on touch); the session page's day buttons are the fallback. Discard in a running session throws it away with nothing logged or marked done. A game finished outside a session is logged in `rg.practiceLog` as `free` (Extra Practice, 1–60 min from start to finish); its result screen offers to count it for an open session this week (`countedFor` on the game). Last-done dates come from `rg.practiceLog` (sessions, routines) and `rg.games` (games). Routines live in `ROUTINES` in sessions.js: steps with minutes, drills, prompts and tap counters (tally rows, optional pass mark), each step with its own countdown; results are saved in `rg.practiceLog` (`routine`, `results`). Center Strike / Startline comes from Dane Cvetkovic's one-hour range routine Short (the 10-min warm-up is our addition). Face Control / Tempo comes from his "full range session if you want to break 80" Short (3 + 20 + 20 + 20 = 63 min). Technical Chipping (5 + 17 + 8) and Technical Putting (6 + 12 + 12, spiral can finish early) are the owner's own; a session with one routine starts it automatically.
- Benchmark games: Ball-Striking Combine and Wedge Combine (SkyTrak carry + offline → feet from target; result = handicap the proximity plays like, Shot Scope bands; the Wedge Combine starts at 30 yd and its 30–40 yd band uses Lou Stagner's Arccos medians from the rough, 0–20 hcp, compared with my median; old 50-yd wedge games keep variant `wedge`, new ones are `wedge30`; Distance Ladder wedges start at 30 yd as set `wedges30`, the old 40-yd `wedges` set stays for past games), Chipping Combine (`chip20`: 4 chips each at 10, 15, 20, 25, 30 yd; zone taps; per-distance median vs Lou Stagner's Arccos medians from the rough, 0–20 hcp, newsletter #27; result = average plays-like handicap; the first short/medium/long version `chipc` is hidden but its games still open), Up-and-Down 18 (strokes vs shots-to-finish × 18), SkyTrak Combine (log only). Use real published numbers only, preferring Lou Stagner's; leave unpublished values out (null, shown as —) rather than estimating. Ball-Striking and Wedge Combines score each target distance on its own benchmark (`benchFor`): 30–40 yd Lou's rough medians (#27), 50–129 yd Lou's fairway averages in 5-yd buckets (#96, `LOU_WEDGE_AVG`, medians also stored), 140+ yd Shot Scope (Lou has none); result = average plays-like over distances; new games carry `v:2` (variants `bsc2`, `wedge2`). Drives are shown against Lou's solid-drive % by handicap (#137, `LOU_SOLID`). The owner subscribes to Lou's newsletter and is signed in to it in the built-in browser. Routine steps can have a `pick` (e.g. Farthest Spiral Distance, 3–8 ft) as well as tallies.
- Title Case: buttons, card titles and headings get `text-transform:capitalize` from one CSS rule (elements already shown in capitals keep `uppercase`); write their source text in Title Case too. Sentences, hints and the user's own text stay as written.
- Check-in is once a day (Nov 18): the first session of the day asks the three questions (Are you having fun? / Is golf getting in the way of real life? yes/no; happiness quotient 1–10) before the clock starts; later sessions that day start straight away (`run.ci.start=="day"`). Every session ends on Done For Today?: Check Out For Today (the same questions) or More Practice Later; until the day is checked out, the Practice home shows a Check Out card. Saved to `rg.checkins` ({run,date,when,fun,life,hq,at}); a day's check-in = its first start and last end (`dayCI`). Insights groups by day. Discarding a session drops its check-in. The Practice home shows the week's total practice time under the heading.
- Lock screen and section alarm (Nov 18): while a session runs, an `<audio>` element (`Lock`) plays generated 8 kHz WAV clips: a near-silent 40 Hz hum (so Chrome counts the page as playing sound, keeps it awake with the screen off and shows a lock-screen card), with the alarm chime baked into the samples at the section's end, rising evenly in loudness from very quiet (`START_GAIN` 0.003, -50 dB) to full over `RISE` = 30 s (media volume caps it). Nov 18: the old start (0.04 over 20 s) sounded loud from the first beep on a phone speaker. Test plays a 12 s sample of the same rise. Clips are 5-minute pieces, remade on `ended`. Media Session card: title = section (or block) and its time, artist = block time and practiced (or practiced and session time), position bar = the section; Pause on the lock screen pauses the session, or just stops the sound while the alarm rings. Web Audio (`Alarm`) is only a fallback when the clip can't play. A Time's Up bar (on any tab) has Stop Sound and Next. On/off and Test in the clock panel (`rg.settings.alarm`). Pausing stops it. Tempo sets `window.__tempoOn` while its tones play, and the session leaves the lock screen to it then.
- Open Practice (Nov 19): an unstructured session started from the card under the week plan (`#practice/open`): pick a discipline (Full swing, Wedges, Chipping, Putting; required, so Insights files the minutes), then Count Up (no alarm, clock counts up until Finish Session) or Countdown (10–90 min chips or ±5 stepper, 5–180; alarm at zero like any block). A third choice, Already Practiced (Nov 19), saves time done without the clock: minutes (1–300, chips/typed/±5) and the day (today or earlier); written straight to `rg.practiceLog` with `manual:true` (no run, no check-in, no timer); the summary says "entered afterwards". While a session runs, `#practice/open` offers only Already Practiced. Last count-up/countdown choice remembered in `rg.settings.open` (the discipline is asked each time). The block is `{s:"open",disc,title:"Open Practice · <Disc>",min,up}`; `sOf(b)` stands in for `SESS[b.s]` everywhere in the runner (never add "open" to `SESS`: the week plan would pick it up). Uses the once-a-day check-in, lock screen and Done For Today like other sessions; logged in `rg.practiceLog` with `open:true` (and `up:true` for count-up), shown under Extra Practice, never marks a planned session done; Edit Session can change its discipline. Matching notes: General plus the discipline's boxes.
- Insights charts: tap to show the numbers; they stay after the finger lifts until a tap elsewhere (`bindTip`). Charts redraw only when the width changes.
- Free-text boxes (Notes, best shots, tags, course names, SkyTrak note) have `spellcheck="false"`: Chrome's own spelling popup fought with the keyboard's suggestions and pulled focus out of the box.
- Routine steps can also be a graded shot sequence (`seq`: speeds × per-speed count, the app calls the club, every club at least once per speed; each shot graded on line / in window).
- `const` globals (Notes, Sessions, Store) are not on `window`; check them with `typeof`, not `window.X`.
- Tempo's `render()` touches every `.chip` on the page; don't reuse that class name in other tabs.
- Tempo decisions: always 30 fps; ratio lock on by default; count-in gap = backswing + downswing frames; no rep counter; screen wake lock off by default.
- The project plan lives in the claude.ai Golf Game project (`claude/golf-app-plan.md`). Update it at the end of each session.
